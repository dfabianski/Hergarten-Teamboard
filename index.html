Dieses Skript speichert automatisch Benutzer & Passwörter (Tab 'Users'), Teams (Tab 'Teams') und Aufgaben (Tab 'Projects') in deiner Tabelle.

So aktualisierst du dein Skript:

  1. Öffne deine Google-Tabelle → Menü Erweiterungen → Apps Script.
  2. Ersetze den gesamten bestehenden Code durch den Code unten (Klick auf „Code kopieren“).
  3. Klicke auf Bereitstellen → Bereitstellungen verwalten:
    • Klicke auf das Stiftsymbol (Bearbeiten)
    • Version: Neue Version
    • Zugriff: Jeder
    • Klicke auf Bereitstellen
